# Data collection

## Ways of data collection

No data is collected without explicit user input.
The only data collected is collected in the form of an input field prompted at the start of the application when choosing to create a new garden.

## Data collected

The data collected in that way is limited to only the address filled in into the input field.

# Data processing

The address data is only used to get the cadaster information from the API.

# Data storage

user created gardens are saved locally
